# Security Policy

## Reporting a Vulnerability

This fork does not currently publish a dedicated private disclosure address or any guaranteed response SLA.

For non-sensitive reports, please open a GitHub issue in this repository:

- https://github.com/Daytona39264/mcpserver-grok-plugin/issues

If your report includes exploit details, credentials, or other sensitive information, do **not** post those details publicly. Instead, open a minimal GitHub issue requesting a private follow-up path from the maintainer before sharing the full report.

If GitHub's private vulnerability reporting or Security Advisories are enabled for this repository in the future, reporters may use that GitHub-provided flow instead.

## Scope

Please include:

- affected file paths or workflow names
- reproduction steps
- expected vs. actual behavior
- any known impact or workaround

This repository is a fork of the upstream SharpNinja project. When a report appears to affect both repositories, note that in the issue so the maintainer can coordinate any needed upstream follow-up.
